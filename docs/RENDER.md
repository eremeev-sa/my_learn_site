# Прежний вариант Render

Эта инструкция заменена: Render с постоянным диском требовал платный тариф. Платная конфигурация удалена из проекта.

Используй **[бесплатный вариант Cloudflare Workers + D1](CLOUDFLARE.md)**. Сначала перенеси прогресс и проверь вход, затем отключи старую публикацию GitHub Pages. Если ты уже успел создать платные ресурсы Render, проверь Billing и удали ненужные сервисы/диск в своём аккаунте после сохранения данных; изменение GitHub-кода не отменяет платежи Render.
