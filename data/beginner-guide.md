# Dev Growth — инструкция новичка

Старт: **19 октября 2026 года, понедельник**. Первая неделя: 19–25 октября.

Цель — около 5,5 часов практики в неделю. Трекер — сайт, а учебный Developer Assistant — отдельный C#-проект.

## 1. Подготовка

- [ ] **Установлен .NET SDK**. SDK — набор инструментов для создания и запуска C#-программ. Выбери поддерживаемую LTS-версию SDK для своей системы. Runtime отдельно недостаточно: нужен именно SDK. [Открыть инструкцию](https://dotnet.microsoft.com/download)
- [ ] **Есть редактор для C#**. Установи Visual Studio Code и расширение C# Dev Kit либо используй уже настроенную Visual Studio. Редактор — место, где ты будешь читать и менять код. [Открыть инструкцию](https://code.visualstudio.com/docs/languages/csharp)
- [ ] **Установлен Git**. Git хранит историю изменений кода. Пока достаточно установки; команды изучишь постепенно. Если Git уже есть, повторно ставить его не нужно. [Открыть инструкцию](https://git-scm.com/downloads)
- [ ] **Создана отдельная папка для практики**. Например, Documents/DevGrowth. Сюда складывай учебные проекты. Папка сайта-трекера и твой учебный C#-проект — разные проекты.
- [ ] **Первая программа запустилась**. Выполни команды ниже и проверь, что в терминале появился Hello, World!. Затем измени строку и запусти программу ещё раз.

## 2. Первая программа

Вводи в терминал по одной команде:

```sh
dotnet --version
dotnet new console -n FirstSteps
cd FirstSteps
dotnet run
```

Ожидаемый вывод: `Hello, World!`. Если dotnet не найден, проверь установку SDK и перезапусти терминал. Если папка уже существует, перейди в неё, не создавая проект повторно.

Замени содержимое Program.cs следующим примером:

```csharp
// Создаём список строк — названий задач.
var tasks = new List<string> { "Изучить коллекции", "Написать первый код" };

// Добавляем ещё одну задачу.
tasks.Add("Объяснить, как работает список");

// Выводим каждую задачу в терминал.
foreach (var task in tasks)
{
    Console.WriteLine(task);
}
```

Запусти `dotnet run`, добавь свою задачу и объясни работу списка.

**Готово, когда:** Программа запускается, список выводится, задача находится по ID; ты можешь объяснить выбор List или Dictionary.

**Готово, когда:** Недельная заметка заполнена, выполненные задачи отмечены, следующий небольшой шаг выбран.

## 4. Как пользоваться сайтом

1. **Открой «Моя неделя»**. Здесь пять направлений: основная тема, короткий AI-блок, практика проекта, коммуникация и обзор. Стрелки переключают недели. Даты считаются от выбранного старта — 19 октября 2026 года.
2. **Выбери одно видео, а не все**. Несколько ссылок — это альтернативы. Посмотри подходящий раздел на 15–45 минут. RU и EN обозначают язык. Подробные подсказки первой недели находятся под каждой задачей.
3. **Сразу попробуй в коде**. Не просто перепечатай пример: измени данные, добавь свой случай и проверь результат. Для сложной темы вернись к базовым понятиям из инструкции.
4. **Отмечай готовый результат**. Чекбокс означает, что ты сделал практику и можешь объяснить её. Открытие видео само по себе не завершает задачу. У каждого задания первой недели есть критерий готовности.
5. **Запиши вывод и сохрани копию**. Внизу недели есть заметка с автосохранением. Раз в неделю экспортируй SQLite-базу в настройках. Чтобы продолжить на телефоне или другом компьютере, импортируй её там.
6. **Подстрой расписание**. Открой «Расписание», измени время и сохрани. Для напоминаний скачай файл календаря .ics и импортируй в своё приложение календаря. MAX подключается отдельно в настройках GitHub.

## 5. Словарь

- **C#** — Язык, на котором ты будешь описывать логику программы.
- **.NET SDK** — Инструменты для создания, сборки и запуска проектов на C#.
- **Терминал** — Окно, в котором команды вводят текстом. Например, dotnet run запускает проект.
- **Переменная** — Имя для значения, с которым работает программа.
- **List / Dictionary** — Список элементов и словарь «ключ → значение». Разные способы хранить данные в памяти.
- **Nullable** — Тип, который допускает отсутствие значения — null. Его нужно обрабатывать явно.
- **Класс** — Описание объекта: какие у него данные и что с ним можно делать.
- **Git / репозиторий** — Система истории изменений и папка проекта с этой историей. GitHub размещает репозитории в интернете.
- **Backend / API** — Серверная часть приложения и правила, по которым к ней обращаются другие программы.
- **PostgreSQL / SQLite** — Две разные базы данных. PostgreSQL изучаешь для своего проекта; SQLite уже хранит прогресс этого трекера.
- **LLM / токен / контекст** — Языковая модель; небольшой фрагмент текста; информация, которую модель видит в конкретном запросе.
- **README / рефлексия** — Инструкция к проекту и короткая запись того, что получилось, что непонятно и что делать дальше.
